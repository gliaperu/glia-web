# Sitio web de GLIA Peruana

Repositorio del sitio web institucional de Asociación GLIA.

## Objetivos del sitio
- Facilitar propuestas de alianzas.
- Recibir expresiones de interés para voluntariado.
- Presentar el propósito y las líneas de acción institucionales.

## Dominio previsto
glia.org.pe

## Plataforma prevista
Sitio estático alojado en Cloudflare Pages.
